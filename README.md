# HOWMU

**Know before you pay.**  
결제하기 전에, 얼마인지부터.

HOWMU(하무)는 여행지에서 본 가격을 내 기준 통화로 즉시 바꿔 보여주는 모바일 웹 POC입니다.

## 실행

```bash
npm install
npm run dev -- --host 0.0.0.0
```

같은 Wi-Fi의 휴대폰에서는 개발 컴퓨터의 로컬 IP와 화면에 표시된 포트로 접속합니다.

## 확인

```bash
npm test
npm run lint
```

제품 요구사항과 향후 방향은 [`docs/PRD.md`](docs/PRD.md)에 정리되어 있습니다.
