# HOWMU 모바일 현지 가격 확인 POC PRD

## 1. 문서 정보

- 제품명: **HOWMU**
- 소비자용 워드마크: **howmu?**
- 한국어 호칭: **하무**
- 브랜드 메시지: **Know before you pay. / 결제하기 전에, 얼마인지부터.**
- 단계: 모바일 웹 POC
- 대상 사용자: 해외여행 중 가격표, 메뉴판, 상품 가격을 확인하는 한국인 여행자

## 2. 문제와 가설

여행자는 현지 통화로 적힌 가격을 봐도 자신의 기준 통화로 얼마인지 빠르게 판단하기 어렵다. 검색이나 일반 계산기는 통화와 숫자를 반복해서 입력해야 해 결제 직전의 짧은 순간에 쓰기 번거롭다.

이번 POC는 사용자가 여행지 통화를 한 번 설정한 뒤 숫자만 입력하면 즉시 원화 금액을 확인할 수 있을 때, 현지 가격을 이해하고 구매 여부를 판단하는 시간이 줄어드는지 검증한다.

## 3. 핵심 사용자 경험

1. 첫 실행에서 기준 통화는 KRW로 미리 설정된다.
2. 사용자는 검색으로 여행지 통화를 고른다.
3. 메인 화면의 숫자 패드로 현지 가격을 입력한다.
4. 입력할 때마다 저장된 환율로 원화 결과가 즉시 갱신된다.
5. 두 통화는 상단에서 언제든 바꾸거나 서로 교환할 수 있다.

대표 검증 과제는 “태국에서 430바트 가격표를 봤다. 원화로 얼마인지 확인해 보라.”이다.

## 4. 기능 요구사항

### 첫 실행과 통화 선택

- 한국어 화면과 KRW 기준 통화를 기본으로 제공한다.
- 첫 실행에서는 여행지 통화를 선택해야 계산 화면으로 이동한다.
- 통화 코드, 한국어 이름, 영문 이름으로 검색할 수 있다.
- 선택한 통화와 첫 설정 완료 여부를 기기에 저장한다.

### 계산기

- 숫자, `00`, 소수점, 한 자리 삭제, 전체 삭제를 제공한다.
- 입력값은 정수 최대 12자리, 소수 최대 2자리로 제한한다.
- 입력 중에는 네트워크 요청 없이 저장된 환율로 계산한다.
- 결과는 통화별 자릿수와 기호에 맞게 표시한다.
- 동일한 통화를 선택하면 기존 통화쌍을 교환한다.

### 환율과 오프라인

- Frankfurter v2의 통화 목록과 최신 환율을 사용한다.
- 통화쌍별 환율, 환율 기준일, 가져온 시각을 기기에 저장한다.
- 앱 시작과 통화 변경 시 저장값을 먼저 사용하고, 6시간 이상 지난 값은 백그라운드에서 갱신한다.
- 갱신 실패 시 마지막 저장 환율과 기준일을 보여주고 계산을 계속한다.
- 저장된 환율이 없으면 인터넷 연결이 필요하다는 상태를 명확히 안내한다.
- 한 번 온라인으로 연 뒤에는 앱 셸을 다시 열 수 있도록 오프라인 캐시를 제공한다.

## 5. 화면과 브랜드

- 메인 화면은 `howmu?` 워드마크, 통화 선택, 입력 금액, 환산 결과, 숫자 패드, 환율 상태로 구성한다.
- 첫 실행에서 `HOWMU 하무`를 한 번 병기해 발음을 학습시킨다.
- 물음표를 앱 아이콘과 빈 입력 상태의 핵심 시각 요소로 사용한다.
- iPhone safe area와 최소 44px 터치 영역을 지킨다.
- 야외에서도 읽기 쉬운 고대비 밝은 테마를 사용한다.
- 카메라·프로필 등 미동작 메뉴는 POC 화면에 노출하지 않는다.

## 6. 성공 기준

- 처음 방문한 사용자가 별도 설명 없이 20초 안에 여행지 통화를 설정한다.
- `430 THB` 입력 시 매 입력 결과가 100ms 이내에 반영된다.
- 숫자 입력 중 네트워크 요청이 발생하지 않는다.
- 새로고침 뒤에도 선택 통화와 마지막 환율이 유지된다.
- 설치한 앱을 네트워크 없이 다시 열고 마지막 환율로 계산할 수 있다.
- 관찰 테스트에서 과제 성공 여부, 소요 시간, 막힌 지점, 결과 신뢰도, HOWMU의 예상 발음과 브랜드 기억도를 기록한다.

## 7. 향후 제품 방향

실제 두 번째 기능이 구현되는 시점에 하단 메뉴를 도입한다. 메뉴 구조는 `계산기`, `카메라`, `프로필`의 세 가지다.

### 계산기

장기적으로 여행 국가 설정에 국가 코드, 통화, 주요 언어를 연결한다. 이번 POC에서는 국가·언어 모델을 만들지 않고 기준 통화와 여행지 통화만 저장한다.

### 카메라

- 계산기에서 설정한 여행 국가의 통화와 주요 언어를 인식에 활용한다.
- 실시간 화면에서 가격으로 보이는 숫자를 감지해 기준 통화로 변환한다.
- 촬영한 상품과 가격을 분석해 현지 시세 대비 저렴함, 적정함, 비쌈과 근거를 안내한다.
- 예: 태국 야돔의 종류, 규격, 묶음 수량, 판매 지역과 표시 가격을 확인해 적정성을 판단한다.
- 적정 가격 판단에는 지역, 매장 유형, 상품 규격, 수량, 기준일, 데이터 출처와 신뢰도가 필요하다.
- OCR, 상품 인식, 가격 데이터 제공처와 판정 기준은 POC 이후 별도 탐색 과제로 둔다.

### 프로필

기준 통화, 여행 국가, 언어, 표시 형식과 앱 설정을 관리한다. 계정, 여행 기록과 즐겨찾기는 사용자 검증 이후 결정한다.

## 8. 이번 POC 제외 범위

- 하단 메뉴 UI
- 카메라 권한, 실시간 OCR과 상품 인식
- 적정 가격 판정과 비교 데이터 수집
- 프로필, 마이페이지, 로그인과 서버
- GPS와 자동 국가 인식
- 행동 분석 SDK
- HOWMU Scan, Compare, Nearby, Lens, Report 실제 구현
